# Constants

Centralized constant definitions for the project.

## Files

- `node.ts` - Node dimensions, colors, labels, and core kinds
- `canvas.ts` - Canvas settings, zoom limits, and dimensions
- `sidebar.ts` - Sidebar dimensions and simulation timing
- `storage.ts` - LocalStorage keys
- `index.ts` - Re-exports all constants

## Usage

```typescript
import { NODE_W, KIND_COLORS, DEFAULT_SCALE, STORAGE_KEYS } from "@/constants";
```
